редактируемого Aseprite — в блоке исходников. PNG встроены в viewer-data.js,
поэтому Canvas и скачивание работают и через file:// без fetch/CDN.

## Происхождение

Арт создан и анимирован настоящими запросами PixelLab. `source/*-request.json`
содержат точные prompts/seed; `*-receipt.json` — квитанции; `*-result.json` —
завершённые задания и галерею. `raw/*/download-audit.json` фиксируют SHA-256
каждого исходного PNG. Все89 полученных кадров13заданий сохранены, включая
отложенные варианты. В итоговых4клипах60кадров; вместе с текущими ресурсами
и фонами viewer использует108уникальных native PNG.

Первый цельный северный клип отклонён из-за поворота корпуса вбок. Для итогового
PixelLab отдельно создал северные overhead/contact позы, затем анимировал
подъём, удар и восстановление между ними. Первый наземный диск оказался белым
и плотным; заменён открытым контуром с ограниченной медной палитрой. Серый конец
первой ударной анимации заменён отдельным PixelLab dissolve. Подробности отбора
и все13job IDs — `source/generation-summary.json`.

Подготовка входа: исходная северная модель192² перенесена на256² с отступом
`[32,48]`, без изменения её пикселей/размера. Для style reference использован
native128² crop той же модели. Дальнейшей ручной перерисовки, перекраски,
масок, покадрового масштабирования/выравнивания AI-кадров нет. Цветовая коррекция
двух опорных поз выполнена самим PixelLab при генерации. Экспорт GIF использует
ограничение формата10 мс; Aseprite/Canvas хранят точные миллисекунды.

Потрачено47генераций подписки:1399.95 →1352.95, кредиты$0 →$0.
Одна начальная ошибка длины prompt не создала задание и не списала генерации.

## Проверка и воспроизведение сборки

`scripts/prepare-ash-warden-north-meteor-review.mjs` готовит native references
и неизменяемый runtime baseline. `scripts/collect-pixellab-spell-review.mjs`
скачивает исходники по завершённым result. `scripts/build-ash-warden-north-meteor-review.mjs`
проверяет baseline, собирает manifest/viewer/native sheets и Lua для Aseprite.
`source/sequences.json` задаёт отбор и темп. `source/export.lua` сохраняет
4Aseprite/GIF через headless Aseprite, без рисования новых кадров.

Проверки и фактические скриншоты описаны в
`docs/art/ASH_WARDEN_NORTH_METEOR_REVIEW_V1.md` от корня проекта.
Итог интеграции и игровые скриншоты — в `../ash-warden-pixellab-runtime-v1/`.

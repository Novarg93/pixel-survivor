# Mage Hero V2 — 2026-11-08

Новая модель из `art/main-hero-mage/abilities/hero-model/` подключена в игру.
Все восемь направлений используют собственные кадры, без зеркалирования.

## Набор и поведение

- 8 idle: южный использует готовый цикл, остальные — соответствующую позу
  исходного листа. Walk и Run: по 16 кадров на все 8 направлений.
  Сохранены выбранные ранее S/SE/NE/N/NW/SW; E/W догенерированы.
- Четыре семейства кастов × 8 направлений. Южные клипы импортированы из
  пользовательских PNG; GIF даёт исходную длительность и проверку alpha.
  PNG сохранён как источник цветов: GIF имеет заметные отличия палитры.
- Fireball → fireball; обычная молния и её ультимейт → lightning;
  Armageddon → meteor; Shield, Frost Nova, ледяной и огненный ультимейты
  → defensive. Нет отдельного старого процедурного слоя рук.
- 8 анимаций поражения, по 12 новых кадров + исходная поза. Клип не зациклен,
  результат боя показывается без ожидания его окончания. Урон обозначается
  tint новой модели; возврата к прежнему магу нет.
- Обычный шаг переходит в Run после .65s непрерывного движения; низкая
  аналоговая скорость сохраняет Walk. Скорость/управление персонажем не менялись.
  Полные касты не останавливают обычное движение; ноги в эти короткие моменты
  принадлежат исходному цельному клипу, поэтому возможно небольшое скольжение.
- Lightning Ultimate удерживает pointing-кадры через release/hold/fade,
  затем возвращается в стойку. Palm anchors сверены с пикселями ладоней/искр
  во всех 8 проекциях; луч привязан к ним.

## Runtime и артефакты

64 клипа, 919 кадров в последовательностях; одинаковые изображения делят
место в атласе. Две страницы не больше 2048px; 21954560 RGBA bytes
(20.94 MiB, оценка base-level текстур, не замер VRAM). Сохранены исходники
256×256, runtime использует nearest-neighbor 112×112, trim и точные aliases.
Размер в мире 40×40, pivot (.5,126/128). HP смещён на -44, тень к стопам.
Коллизии, RNG, урон, интервалы заклинаний и ограничения сущностей прежние.

Ключевые файлы: MageHeroAnimation.ts, MageHeroArt.ts, mageHeroPack.ts,
mageHeroManifest.json; GameArt/assetRegistry/GameScene/PlayerHealthBar;
scripts/inspect-mage-hero-sources.mjs, collect-mage-hero-generations.mjs,
build-mage-hero-v2.mjs, import-mage-lightning-repair.mjs,
export-mage-hero-clips.mjs, build-mage-hero-review.mjs.

- Игровой атлас: public/assets/hd/mage-hero-v2/.

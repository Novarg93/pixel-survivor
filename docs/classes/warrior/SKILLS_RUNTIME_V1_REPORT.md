# Warrior skills v5 — интеграция в игру, 2026-11-13

Пользователь принял все навыки последней демки и поручил подключить их в игру. Все 12 финальных клипов / 48 сочетаний v5 теперь доступны в настоящем забеге Warrior. Исправленные северные Cleave, Whirlwind и Throw, Stomp r2, фронтальный Throw r3 и южный пользовательский Whirlwind сохранены точно. Старые отклонённые пробы не возвращались.

## Что подключено

| Навык | Игровое событие и представление |
|---|---|
| Cleave | Три обычных C1/C3/Heavy сохранены; каждый четвёртый жест — принятый skill Cleave. Встроенный слеш не дублируется. |
| Whirlwind | Один полный body-клип на запуск способности, без сброса на каждом импульсе урона. |
| Ground Stomp | Реальный размеченный удар после 0.65с; принятая трещина появляется в точке попадания, исчезает за 1с. |
| Shield Block | Принятый жест при включении прежнего снижения урона на 50%; защитная индикация действует до окончания баффа. |
| Piercing Throw | Заменяет старые вращающиеся клинки. Копьё выпускается после замаха, летит по прямой, пробивает 3–7 разных целей. |
| Charge | Space, прежнее перемещение за 180мс; отдельные front/north клипы, немедленное прерывание тела и невыпущенного копья. |

N/NE используют северные исходники от выбранной ячейки 4 напрямую; NW отражён. W/SW отражают фронтальный источник; S/E/SE используют его напрямую, как в принятой демке. Это переиспользование принятых ракурсов, а не восемь новых генераций.

Копьё: дальность поиска 360×area, скорость 340px/s, урон (30+12×rank)×damage; один контакт с каждой целью. Release 0.75с front / 0.375с north выбран по реальным контактным листам. Программная текстура полёта оригинальная; её высота 16px отделена от collision position. Используются существующие sweep-collision, projectile pool и лимит 96. ID `blades` сохранён для upgrade IDs и статистики; HUD, карты и эмблема обновлены.

Одновременно готовые специальные навыки занимают один жест за раз, по самому давно готовому cooldown; длительность жеста 0.975с. Движение не блокируется, автоматический урон Cleave продолжается. Это меняет порядок/фактический момент одновременных special-cast; численные damage/cooldown остальных навыков сохранены. Арт живёт по `World.elapsed`, пауза замораживает кадр и замах. Очереди ограничены; teardown уничтожает созданные Phaser Image и отменяет невыпущенное копьё.

# Ash Warden — полная библиотека анимаций

Относительный путь: `art/generated/ash-warden-animation-library-v1/viewer.html`.
Открывается двойным кликом или по адресу
`http://127.0.0.1:5173/art/generated/ash-warden-animation-library-v1/viewer.html`.
Основная библиотека автономна: для переноса сохраняйте всю папку. Исторические
ссылки требуют соседних исходных папок проекта.

В каталоге84элемента: все51клип основного игрового атласа, отдельные ресурсы
автоатак A и дуги B, огненного выброса,4актуальные статичные проекции,
8исходных статик-моделей и15собранных сцен.473PNGслоёв доступны в исходных рамках,
без масштабирования и перекраски. Есть13ссылок на историю разработки.

Сверху доступны все4проекции: юг/север/восток/запад, статично, idle или ходьба.
Открыть нужную проекцию крупно можно кнопками под галереей. Западная ходьба
и атака A зеркалят восточные кадры; южная поза рывка используется и для бокового
движения с игровым зеркалированием. Отсутствующие новые проекции не дорисовывались.

Собранные сцены:

- Автоатаки A/B на восток и запад, автоатаки на север и юг.
- Рывок → огненный удар, отдельный огненный веер1/3/5волн по фазам.
- Каст/предупреждение/падение/удар/след метеорита, Армагеддон.
- Вход/удержание/выпуск ритуала.
- Появление с reveal и наземным VFX, разрушение щита/stagger/восстановление.
- Перегрев/переход в третью фазу и полная смерть с мечом и пеплом.

Сцены сэмплируются с шагом20мс настоящими wardenPose/meleeComboView/flameStrikeView
и getters FinalEncounter. Сохраняются текущие ускорения, зеркалирование, опоры,
слои третьей фазы, порядок глубины и родные кадры. Места падения, траектория
рывка и длина удержания ритуала выбраны для просмотра; это не боевая симуляция.

Управление: раздел/статус/проекция/поиск, быстрый выбор клипа, фаза1/2/3,
игровой/исходный темп, фон, масштаб и вписывание, маг для масштаба,
pause/restart/seek/шаг кадра/повтор, опоры, фильмстрип всех кадров.
Инспектор даёт PNG каждого слоя текущего кадра через встроенный dataURL,
поэтому скачивание доступно и при file:// без чтения Canvas через CORS.

Статусы различаются явно: «В игре», «Собранная сцена», «Компонент», «Архив»
и «Исходная модель». Старая south-melee и отключённая подсветка автоатаки
не выдаются за используемые сейчас. Слои показываются отдельно и в сочетаниях.

Сборка: `node scripts/build-ash-warden-library.mjs`. Движение сцен задаёт
`scripts/ash-warden-library-scenes.mjs`; `scripts/lib/load-project-ts.mjs`
исполняет доверенные модули проекта установленным TypeScript без запуска Vite.
Manifest хранит точные источники/SHA256, trim offsets, pivots/scales, времена,
сцены и статусы. PNG восстановлены из опубликованных runtime атласов;
пустота вне опубликованного trim заполняется прозрачностью.

Новых генераций и изменений босса нет. Снимок345src/public файлов включает
уже принятое PixelLab-пламя Хранителя затмения; вся библиотека read-only.
Проверки и скриншоты: `docs/art/ASH_WARDEN_ANIMATION_LIBRARY_V1.md`, `screenshots/`.

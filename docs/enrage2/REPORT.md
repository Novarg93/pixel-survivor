Полный запрос содержит Charger/Sorcerer/Eclipse; порядок циклически меняется,
поэтому при одном свободном слоте типы тоже чередуются. Никто не удаляется
для освобождения слота. Пропущенная волна не накапливается.
Старый enrageSpawns не сбрасывается, дополнительно считается endgameSpawns
только для успешных созданий с900s. Живой босс не меняется при новом рождении.

Для II tick`t` и успешного II индекса`n`:

- Movement factor: `1+.04t+.005(n−1)`, max1.6 для магов/1.45 для Charger.
- Frequency factor: `1+.06t+.01(n−1)`, max3.
- Projectile factor: `1+.03t+.003(n−1)`, max1.6.
- Залп: `7+floor((n−1)/6+t/8)`, max11.

Эти значения — один снимок при рождении поверх прежней capped базы, а не
повторное умножение. Слагаемое индекса внутри той же линейной формулы
даёт последовательное усиление и для трёх боссов одного интервала.
Минимальные floors сохраняются: windup/post-teleport tell≥.5,
recovery≥.2, подход между кастами≥.25, teleport interval≥2.8.
До15 старые timings не меняются. Частота применяется к старому cooldown
и его старому floor альтернативными ветвями max, а не дважды к одному времени.
У Charger pursuit ограничен прежней базой×1.45, реальный charge≤320px/s,
warning.5, cooldown≥.75, recovery≥.12, max charge distance240; его AI прежний.
HP/damage боссов при одинаковом времени создания прежние.

уведомление и radar marker. Старого ожидания попадания/64px/10:00 нет;

Собственный successfulSpawns увеличивается только при реальном создании.
Snapshot содержит индекс, коэффициент и обе скорости; вычисляется однажды
от постоянной скорости героя при рождении, без временного haste и без
последующего пересчёта при баффах/кадрах. Формула `min(2,1+.1(n−1))`.
У трёх участников одной волны разные индексы. Награды, HP, score/XP прежние.

## Ограничения / ручной тест

Пилот читает доступные предупреждения/направления снарядов и реагирует
быстрее человека. Результаты — для указанной сборки и seed; первые18min
полностью не проигрываются, а история индексов восстанавливается. Число
success births у реального пользователя может быть ниже из-за занятых слотов.
Путь/leash обрезают фактический lifetime сфер раньше config TTL. Например,
при предельных290/370px/s путь1800 ограничивает полёт6.21/4.86секундами,
хотя nominal TTL28/24s. Сохранена эта локальная граница; две сферы на owner
являются лимитом, а не обещанием постоянного наличия двух одновременно.
Несколько читаемых по отдельности атак могут пересекаться в сложную комбинацию.
Mobile — viewport desktop Chromium, не физический телефон. FPS короткий,
не обещание постоянных60 на любом устройстве. Рост имеет поздние безопасные
caps, не бесконечную математическую прогрессию.

Следующий шаг — человеческая проверка15–25min: комфорт .5s подготовки,
сочетание трёх боссов, несколько Guardian×2, уход из зоны, обычное движение
против Blink. Арт-стиль и пользовательские способности не изменялись.
Task.done для внеплановой задачи не создавался. Docs/PNG локальны по .gitignore.

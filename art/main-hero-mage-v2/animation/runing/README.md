# Mage V2 — демонстрация бега

Доступно [демо на северо-восток](north-east/viewer.html): start1–5/end10–13 из
run-start-end и loop5–10 из run-loop. В общем viewer теперь три вида и оба
исходных листа нового набора. Разбор — [north-east/README.md](north-east/README.md).

Добавлен [северный вариант из north.png](north/viewer.html): разгон1–3,
цикл4–9, завершение10–13. Выбор «Вид» переключает передний/северный набор.
Подробности северного разделения и проверок — [north/README.md](north/README.md).
Ниже описан передний вариант.

Открыть `viewer.html` двойным щелчком: сервер и интернет не требуются.
При локальном Vite сервере путь — `/art/main-hero-mage-v2/animation/runing/viewer.html`.

Автопоказ: покой → разгон → несколько повторов бега → остановка → покой.
Кнопки «Бежать» и «Остановиться» переключают на ручное управление.
Есть пауза (также пробел вне элементов управления), шаг по кадрам, ползунок,
темп ×0.25/0.5/1/1.5/2, поле с прокруткой и шахматный фон прозрачности.
Можно отдельно просмотреть каждую стадию и полный исходный run-loop.

| Стадия | Кадры исходного листа, начиная с 1 | Темп | Длительность |
| --- | --- | --- | --- |
| Разгон | 1–13 | 100 мс/кадр | 1300 мс |
| Бег | **4–11**, по уточнению пользователя | 90 мс/кадр | **720 мс** |
| Остановка | 4–13 | 100 мс/кадр | 1000 мс |

Каждый исходный PNG — сетка 4×4, 13 заполненных ячеек 96×96.
Из run-loop исключены 1, 2, 3, 12 и 13; стык цикла — **11 → 4**.
Разгон заканчивается кадром13 и входит в цикл на кадре11. При запросе остановки
завершается текущий шаг до кадра5, затем показывается кадр4 run-stop и его хвост.
Это исключает начальную стойку/повторный разгон из исходной остановки.
При ручном управлении задержка до остановки ограничена одним циклом бега.

В PNG нет таймингов анимации: значения выше выбраны для демонстрации.
Привязка всех стадий фиксирована: x46/y84 исходного холста96×96.
Пиксели, прозрачность, оттенки и изменения позы сохранены из пользовательских листов.
Поза и ракурс слегка меняются внутри исходного бега; новые кадры не дорисовывались.
Прокрутка фона иллюстрирует движение, согласование со скоростью игрового мира
остаётся отдельной задачей. Подготовлена локальная демонстрация; runtime игры не менялся.

## Файлы

- `run-start.png`, `run-loop.png`, `run-stop.png` — пользовательские исходники.
- `prepared/` — производные PNG/GIF стадий; `run-raw-loop.*` сохраняет все13 поз.
- `animation.json`, `viewer-data.js` — тайминги, исходные номера кадров, SHA256.
- `run-timeline.js` — часы и переходы демонстрации; `viewer.js/css/html` — просмотр.
- `screenshots/` — реальные Canvas/UI снимки и JSON с результатами браузерных проверок.
- Builder: `node scripts/build-mage-running-demo-v2.mjs` из корня проекта.

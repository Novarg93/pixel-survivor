# Hooded Mage B — боковой общий каст

Выбор пользователя: **B, «Капюшон»**, 9 ноября 2026. Исходник:
`art/generated/mage-style-exploration-v1/originals/b.png`, PixelLab asset
`b005a8f2-9d79-5b5f-b26d-57f165f20ae9`. Исходный PNG сохраняется побайтно.

База: `docs/art/PIXEL_SURVIVOR_ART_STYLE_GUIDE.md`. Средняя детализация,
длинная индиговая мантия, тёмная сине-зелёная одежда, один простой ремень,
минимум декора. Эталон мира — актуальный игровой Ash Warden; его PNG не отправлять
в генератор. Для этой задачи достаточно уже существующего в PixelLab варианта B.

## Поставка

- Один правый боковой ракурс; левый — точная локальная горизонтальная копия.
- Общий каст без встроенного Fireball/Lightning/VFX.
- Три высоты цели при одном и том же ракурсе корпуса: прямо, выше, ниже.
- По6кадров: исходная стойка → подготовка → замах → выпуск → follow-through →
  восстановление. Кисть в release-позе тянется к цели; ноги и опора мантии стабильны.
- Native96×96 transparent PNG, рамка с запасом для вытянутой руки.
- Не добавлять новую броню, мелкие узоры, staff, оружие или elemental glow.
- Прозрачные originals, зеркальные PNG, GIF, sheet/manifest/timings, viewer
  с pause/speed/frame step и целями, source/job/seed/billing metadata.

## Ограничения

Только art-pass. Не менять production-код, игровые события и принятые атласы.
Не генерировать8направлений, отдельную магию каждой стихии, walk/death/idle loops.
Переход от будущего движения к этим позам и runtime hand origins — следующий этап,
после просмотра анимаций. Viewer не выдаётся за интеграцию в игру.

## Проверки

Native dimensions/PNG CRC/alpha/clipping; фиксированный canvas/pivot;6различимых
поз в каждом клипе; зеркальные пиксели точно соответствуют правым; landmarks и
timings настраиваются явно, без кадрового bbox-центрирования. Просмотреть Canvas
desktop/mobile и file/HTTP, проверить паузу, покадровый просмотр и смену цели.
SHA256 существующих src/public/assets/art до/после; ESLint и npm run check.

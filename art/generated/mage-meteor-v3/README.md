# Mage Meteor V3 — серо-медный обломок

Оригинальный программный pixel art по проектному ART_STYLE_GUIDE, уже в игре.
Демо: [viewer.html](viewer.html), HTTP или двойной клик с диска. Есть режим
«Только подсветка», пауза, шаг, seek, скорость, два настоящих игровых фона.
Сравнение использует текущую модель Ash Warden в её реальном мировом масштабе.

Серо-медный осколок с тремя крупными гранями, коротким тёплым хвостом и одним
светящимся краем отличается от крупного вулканического камня босса. Удар мага
даёт пять мелких осколков и сухую пыль, без лавовых трещин и тяжёлого кольца.
Рисунок создан независимо, без импорта boss generator/pixels. Копии boss PNG
в source используются исключительно для просмотра сравнения.

|Клип|Кадры / длительность|Назначение|
|---|---|---|
|flight|4×50мс,цикл|Анимация короткого хвоста вокруг неподвижного камня|
|illumination|12×40мс|Самостоятельное мягкое освещение области приземления|
|impact|6×60мс|Маленький всплеск и осколки, последний кадр прозрачный|
|ground|8×100мс|Быстро остывающий сухой след, последний кадр прозрачный|

Все кадры128², pixel clusters2×2. Flight/impact/ground pivot64,80; свет64,64.
Body/impact canvas56world px, видимый stone приблизительно13world px.
Ось хвоста45° от screen-up вправо, движение в противоположную сторону;
игровая дистанция192.4 и время~218мс сохранены. Пауза использует World.elapsed.

Подсветка: радиальная альфа от0 до69/255, без белого ядра и кольца. PNG/Aseprite
хранят точную дробную альфу. В runtime первые8кадров соответствуют прогрессу
полёта, последние4 затухают за160мс после удара. Она показывает реальный радиус
AoE, а размеры камня/удара не растут с Area. Для reduced flash альфа×0.6.

Прозрачные sheets: `source/{flight,illumination,impact,ground}.png`.
Каждый клип отдельно редактируется в одноимённом `.aseprite`.
GIF illumination-grove-preview наложен на Grove: GIF не умеет дробную альфу.
Остальные GIF прозрачные. Ground GIF может объединять соседние одинаковые
кадры с сохранением общей длительности800мс. Runtime использует точные PNG.

Пересборка: `node scripts/build-mage-meteor-v3.mjs`.
Экспорт Aseprite/GIF: `aseprite -b --script-param root=<абсолютный путь к этому
каталогу> --script source/export.lua` из корня проекта (полный путь к Lua).
Runtime: `mageMeteorPack.ts`, `MageMeteorPresentation.ts`, `MageAbilityArt.ts`.
30кадров, atlas792×660,2090880RGBAbytes. Старый общий atlas Frost сохранён
побитово; его исторические Meteor-cels больше не выбираются в игре.

Происхождение — source/provenance.json; защищённые SHA256 босса/Fireball —
source/protected.json. PNG/manifest/light-sheet rebuild byte-identical.
Отчёт: `docs/art/MAGE_METEOR_V3.md`; игровые screenshots:
`screenshots/mage-meteor-v3/`, самостоятельное демо — `screenshots/` рядом.

защищены SHA256 в runtime manifest.

## Runtime

`scripts/build-mage-idle-v2.mjs` воспроизводимо собирает26точных кадров в отдельный
atlas384×672,1032192RGBA bytes. Скрипт сам читает GIF durations; Aseprite не нужен
при обычной пересборке. Выход: `public/assets/hd/mage-idle-v2/atlas.png/json`,
`src/game/art/mageIdleManifest.json`. Команда: `node scripts/build-mage-idle-v2.mjs`.

`mageIdlePack.ts` выбирает кадр по world elapsed. Направления:
E/SE/S — передний вид; W/SW — его flipX; N/NW — спина; NE — её flipX.
Обе проекции сохраняют исходный full-canvas pivot, включая отражение X;
нижняя граница первого кадра задаёт опору каждой базы. Покадрового выравнивания нет.

`MageHeroArt` применяет новый atlas к pose.motion=idle, включая подавленный
hurt-жест. Следующим поручением подключён [пользовательский Walking](MAGE_WALK_V2_INTEGRATION.md)
с теми же scale/pivots. Старые run-start/run-stop в обычном движении не показываются.
[Касты](MAGE_CAST_V2_INTEGRATION.md) также заменены пользовательским набором;
старый phantom больше не показывается. Death пока использует прежнюю модель.
При смене действия восстанавливаются соответствующие origin/size/flip/crop.

Новая видимая высота34.285714world px равна текущему runtime Idle-кадру прежнего
героя. Полный прозрачный canvas имеет displaySize46.358149 из-за другой доли
силуэта в96×96. Collider/скорость/игровые timings и HP bar не меняются.
NEAREST фильтрация включена при загрузке. Дополнительных объектов/таймеров нет.

Rest-hand fallback вычисляется из видимой кисти каждого PNG-кадра с учётомflipX
и нового origin; он не обращается к отсутствующей legacy waist-записи нового
кадра. Основные cast/phantom release anchors остаются прежними.

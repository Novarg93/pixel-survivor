# Cleave: контакт меча и движение ног — 2026-11-13

Исправлена подтверждённая проблема: раньше Cleave наносил урон при выборе цели, затем отдельный renderer ставил жест в очередь. Враг мог умереть до начала замаха. Полный attack-кадр также заменял Run и останавливал видимые ноги при продолжающемся перемещении.

## Изменение поведения

`World.warrior.cleave` теперь хранит настоящий начавшийся удар: вариант, направление, started/duration, hitAt, contactEnd и отметку единственного попадания. `cleaveTiming` читает тот же contact-frame принятого клипа, который используется renderer. HP, смерть, score и XP меняются только в `tickCleave` на контакте. Цели проверяются по текущему положению героя и конусу меча: ушедшая из досягаемости цель не получает отложенный гарантированный урон.

Renderer читает этот удар напрямую. Очереди будущих Cleave-анимаций нет; старый hit-effect не запускает новый взмах. Варианты идут C1 → C3 → Heavy → skill Cleave. Тайминг длинного клипа при необходимости сжимается до действующего cooldown, чтобы восстановление не накапливало запоздавшие атаки. Базовые damage/cooldown/radius сохраняются. Charge, defeat и teardown отменяют незавершённый удар. Пауза и выбор улучшения замораживают общий игровой clock.

Замах и два кадра контакта Cleave имеют приоритет тела; recovery может уступить другому навыку. Автоатака может начать следующий настоящий замах во время другого эффекта. Специальные навыки не вытесняют незавершённый контакт; при возврате показывают свою текущую фазу по исходному времени запуска, без позднего replay с нуля.

## Ноги во время атаки

`WarriorMovingCleaveArt` композитит принятый attack-верх с нижней частью принятого Run. Фаза шага зависит от фактического пройденного расстояния, сохраняется через начало атаки, замораживается при паузе; нижний слой смотрит в направление движения, верх — в направление удара. Исходные PNG/атласы не редактируются. W/SW и NW сохраняют принятую схему зеркал.

Слои получаются программно из уже загруженных кадров и кешируются в одной принадлежащей сцене CanvasTexture. Создаётся не более одного дополнительного Image ног. Маски сохраняют пересекающие талию меч/щит и встроенные яркие слеши с их исходными RGBA. При QA исправлены захват меча из Run и вырезание прямоугольника из baked-slash. Canvas для обработки пикселей использует `willReadFrequently`; обработка выполняется при создании кеша, а не каждый игровой кадр. Image и texture уничтожаются при teardown, на новом run состояние шага сбрасывается.

Это программная композиция, а не новая AI-генерация. Эталон Whirlwind SOUTH, его настройки и все исходники принятых 12 skill-клипов сохранены.

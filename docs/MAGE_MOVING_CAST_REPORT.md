# Mage: раздельная анимация движения и каста

Дата: 2026-11-08. Запрос пользователя: попробовать составной вариант каста на
ходу и временно убрать жест Shield.

Ноги берутся из Walk/Run, верх — из Fireball/Lightning/Meteor/Defensive той же
проекции. Во время движения проекция следует движению, после остановки
возвращается цельный каст к цели. Настоящее движение, автонаведение, урон,
кулдауны и блокировка движения ультимейтами не менялись.

Shield больше не начинает и не перебивает жест, включая shield impact.
Поглощение урона и HUD работают по прежним правилам. Defensive остаётся для
Frost Nova и Frost/Fire Ultimate, Lightning Ultimate использует Lightning.

`scripts/build-mage-hero-waists.mjs` строит `mageHeroWaists.json`:919 anchor
registrations, manifest SHA256, canvas112. Каждый кадр сравнивается с поясом
Idle в той же проекции. Поиск ограничен5px по X и4px по Y. В рантайме два
существующих кадра совмещаются с перекрытием1px; исходные PNG/атласы не меняются.
После пересборки исходного manifest нужно выполнить этот скрипт; unit test
обнаруживает устаревший hash и неполный набор anchor.

Phaser Sprite показывает ноги; один ленивый Image показывает верх. Он делит
исходный атлас, alpha/tint и получает смещение пояса. Тот же offset применяется
к ладони. При остановке, завершении/прерывании каста возвращается полный crop;
верх скрывается и переиспользуется, при teardown уничтожается. Timers/listeners
и render textures не добавлены. Новых генераций и платных вызовов0.

Подтверждён `npm.cmd run check`:893unit/108files, typecheck/lint/build PASS.
Финальные18/18E2E PASS(2.4min): mage-moving-cast, mage-casting, mage-hero-v2,
lightning-ultimate-art. All-direction32 desktop+8portrait; независимые фазы,
pause, реальные цели позади, сохранение Run, совмещение пояса и отсутствие
новых atlas keys. Проверены остановка к цели и повторное начало движения внутри
каста, настоящее Shield absorption без потериHP/перебивания жеста, alpha,
сброс crop на Blink/Hurt/Death и10scene restarts (allocated0/croppedfalse).
Production9/9 PASS(42s), запросы ресурсов не увеличились. Финальный
typecheck/lint после дополнений E2E и git diff --check PASS.

Stress150+3boss+3Guardian:≈59.88medianFPS desktop/portrait, p95frame16.7–16.8ms,
update1.9ms, texture bases132434112/119851200bytes<128MiB. Сценарий mixed

Суммарный textureBytes может меняться из-за переработки чанков при перемещении
камеры; тест проверяет отсутствие новых non-chunk texture keys и общий бюджет.

Просмотрены увеличенные Canvas-контакты всех40 сочетаний, а также
последовательности Fireball/Lightning/Meteor/Frost. Артефакты:
`screenshots/mage-moving-cast/` (42PNG/2JSON; review-contact.png в1280/390),
`screenshots/mage-casting/` (PNG последовательности, filmstrips, видео, JSON).
Видимых разрывов/дыр на просмотренных поясах нет; исходные пиксельные контуры
сохраняют особенности авторских фаз. Блокеров нет, следующий шаг — оценка в игре.

Ограничение: исходные кадры нарисованы целиком, поэтому складки плаща и мелкие
контуры на поясе могут меняться при совмещении фаз. Это не специальная анимация
поворота корпуса для стрельбы назад: на ходу жест сохраняет направление бега,
а заклинание по прежнему поражает выбранную игровой логикой цель.

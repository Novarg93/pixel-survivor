10 выбранных клипов; IDs/asset IDs/receipts сохранены в generation-record/jobs.

## Файлы и визуальная оценка

Каждый raw job содержит исходный кадр + 16 новых PNG. Финальные sheet/strip/
GIF/Aseprite используют ровно frame-01…frame-16. Экспорт без ретуши,
перестановки, выравнивания, зеркалирования или перекраски. JSON описывает
4×4 рамки 256×256. Aseprite batch импортировал strip и экспортировал GIF;
мастера однослойные, не заявляется ручное разделение частей тела.

Темп просмотра отдельно выбран как Walk 80 мс (1.28 с), Run 60 мс (0.96 с);
API выдаёт PNG без длительностей. Viewer self-contained и работает без сети.
Выбор направления, сравнение с исходником, скорость, пауза, кадры и фон.
`selection.json` указывает выбранные версии, исходная слабая SW Walk доступна
отдельно. Ничего автоматически не подключалось в Phaser.

Открыты все 11 полных 16-frame sheets, все пять desktop сравнений и mobile
SW. Общая палитра/костюм узнаваемы. Run имеет более активные руки/колени/плащ,
Walk — спокойный шаг. Selected SW Walk имеет более явную работу стоп.
Художественные ограничения: в диагональных Run SE/NE/NW корпус в середине
цикла поворачивается ближе к профилю; направление не идеально фиксировано.
Некоторые Walk тоже меняют угол плеч. В конце клипы возвращаются в стойку,
что следует отдельно оценить для непрерывной locomotion. Технические тесты
не объявляют эти художественные особенности идеальными/готовыми к интеграции.

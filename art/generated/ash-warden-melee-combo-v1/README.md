# Ash Warden melee combination

Runtime uses B/A alternation for actual East/West basic attacks. Only B renders the RD slash, mirrored for West; A renders no slash. B has no floor AoE light. Its frames0–6 retain their timing, while frames7–11 play twice as fast (650ms windup +275ms finish). South uses overhead without Flame Strike; North retains back-facing B. Special Flame Strike remains separate.

The new slash was generated by RetroDiffusion MCP `rd_animation__vfx`,96×96, seed6110791, task `3ad17111-e4bc-439e-a604-edc186e8111c`. One paid job, $0.07. Full requests, responses, cost estimate and raw output are archived under `slash/` and `preflight/`.

The raw result is a rotating fiery ring with16×200ms frames. The prepared effect keeps warm RD pixels in the forward120degree sector, uses dithered angular taper and an explicit one-shot envelope, then mirrors all prepared frames x=95−x for West. The raw GIF remains unchanged. Runtime uses16×20ms with its maximum visible coverage at the650ms melee hit. Preview GIFs repeat only for review; gameplay renders each attack once.

Current runtime additionally extends arc length by15% in polar angle, preserving radius and radial stroke thickness. `length-115/` and `length-115-west/` contain these separate derivatives. Global sprite scale stays1.65. Base prepared frames and old preview GIFs remain archived as the pre-extension version.

All12 body A PNGs are copied from the original experiment without fitting, rescaling or retouching. New emission masks follow the existing magma-color rule. The runtime atlas is512×1024/2MiB and keeps full source canvas/pivot metadata. Original accepted Warden/Walk/B/C packs remain unchanged.

Reproduce locally from the project root using installed dependencies:

```sh
node art/generated/ash-warden-melee-combo-v1/prepare.mjs
node art/generated/ash-warden-melee-combo-v1/decode-slash.mjs
node art/generated/ash-warden-melee-combo-v1/prepare-assets.mjs
node scripts/build-ash-warden-melee-combo.mjs
node art/generated/ash-warden-melee-combo-v1/verify.mjs
```

`decode-slash.mjs` reads an existing raw GIF, or downloads the existing job result; it never starts generation. If a signed URL has expired, refresh that same task through MCP. Keep `protected-baseline.json` intact. Screenshots and actual auto-attack selection traces are in `screenshots/` and `game-validation-*.json`.

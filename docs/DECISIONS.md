# Решения — интеграция HD Pixel Art

## Дополнение: Runner Art Pack 01

2026-11-01, исходная feature `b2cd57c`. Только Runner; новый образ Ember Strider:
узкая наклонённая фигура, длинные суставчатые ноги, отдельная вытянутая голова,
медные пластины и тёмная подкладка. Он нарисован с нуля программными контурами,
без перекраски Grunt и внешних спрайтов. Два ракурса запечены с верхним левым
светом, чтобы runtime flip не менял направление освещения.

Формулировки «24», «23», «46» интерпретированы как диапазоны 2–4 / 2–3 / 4–6
из Style Guide. Реализованы idle 3, walk 6, hurt 3, death 6; по 18 на сторону,
всего 36 кадров 64×64. Плотность компенсируется прежней логической рамкой 16×16.
Elite Runner использует исходный масштаб 1.4 и исходные модификаторы, без
изменения HP/radius/speed/AI. Каталог честно фиксирует эти реализованные clips.

Выделен отдельный малый статический `hd-runner` (512×408). Старые runner и
runner-walk не генерируются. Core PNG/JSON, Grunt, Warrior и окружение не менялись.
Исходник и воспроизводимая сборка — scripts/runner-art-source.mjs и build-runner-art.mjs.
Pixel QA проверяет все 36 кадров, прозрачные границы, бинарную альфу и разные
рисунки. Обрезание гребня в первых death-позах исправлено в риге складывания,
а не увеличением рамки, смещением pivot или отключением assertions.

Для смерти выбран чистый наблюдатель RunnerAnimation: ссылки на Runner до step,
hp=0 после исчезновения, snapshot финальных x/y/elite. Он различает despawn и
смерть, не внедряет callbacks в World, не сохраняет мёртвых в enemies и не
откладывает XP/loot. Только ранее наблюдавшиеся Runner получают тело; для
рождённых и уничтоженных целиком до первого наблюдения остаётся общий исходный
FX. Пул24 переиспользует старейший визуальный слот при переполнении и очищается
по runId/scene shutdown. Все фазы используют World.elapsed; таймеры не добавлены.

Отдельный тест повторяет burst150 → pool24 → scene restart десять раз.
Исторические файлы screenshots/hd-pixel-art, регенерированные общей матрицей,
восстановлены из HEAD; новые свидетельства находятся в screenshots/runner-pack-01.

## Git-аудит и сохранение

В начале локальные `main`, `origin/main` и `experiment/visual-styles` указывали
на `accf6d5b64cf5be516dc7f479f5830935c4d5a6f` (Rare Guardians & Minimap).
В истории два коммита: `5657ea5` (первый релиз) и `accf6d5`.
Коммитных отличий main↔experiment не было (0/0). Эксперимент находился в
незакоммиченных изменениях: 9 изменённых файлов плюс новые код, тесты, документы,
PNG и JSON результатов; посторонних изменений среди них не обнаружено.

Удалённый main проверен `git ls-remote origin refs/heads/main`: тот же полный hash.
Первый запрос Windows Schannel завершился `SEC_E_NO_CREDENTIALS`; повторный с
одноразовым `git -c http.sslBackend=openssl -c credential.interactive=never`
успешен. Git config, Windows settings, учётные данные и main не менялись.
Fetch для уже имеющегося подтверждённого коммита не требовался.

Чтобы сохранить незакоммиченные материалы именно в экспериментальной ветке,
создан локальный checkpoint **`01aa758`** — `Preserve visual style experiment and
comparison evidence` (36 файлов). Это необходимое изменение исходной ветки для
сохранения работы; её материалы A/B/C не удалены и не переписаны.
После чистого checkpoint выполнено `git switch -c feature/hd-pixel-art main`.
Feature создана от `accf6d5`, merge/cherry-pick всего эксперимента не выполнялись.

Main занят отдельным worktree. Его файлы и соседний проект не открывались и
не изменялись; проверены только Git refs/history и удалённый hash. Git-метаданные
этого worktree разделяются с общим репозиторием, поэтому для add/commit/switch
понадобился разрешённый доступ к общим метаданным. Это не административные права
и не изменение файлов другого worktree. Push/deploy не выполнялись.

## Статический атлас и реестр

`public/assets/hd/core.png` + `core.json` — один production-атлас на 37 кадров.
Phaser preload выполняется только если текстуры ещё нет; при scene.restart
изображение не запрашивается заново. Фильтрация NEAREST, существующий pixelArt
и roundPixels сохранены. Заменённые legacy Warrior/grunt не генерируются.
Mage, другие враги, Guardian, боссы, предметы, остальные способности и UI остаются
рабочими исходными ресурсами, а не заменяются новыми заглушками.

`assetRegistry.ts` содержит единый каталог всех текущих семейств, их явный
статус, источники, размеры, pivot, масштабы и clips. Логические размеры
отделены от исходника; `setDisplaySize` компенсирует разрешение. В World,
EnemySystem, способности, баланс, лут и radar реестр не импортируется.
Файлы этих систем не изменялись. Сохранён исходный приоритет масштабов tank/elite/boss.

`GameArt` читает World, устанавливает кадры и переиспользует тени/Cleave.
Новых таймеров, вводных listeners или каналов bridge нет. Очистка принадлежит
Scene.SHUTDOWN; core живёт до уничтожения Phaser Game. Чанки остаются ограниченными,
удаляются Image и соответствующие TextureManager textures.
Диагностика доступна только через исходный dev/test hook. Для проверки таймеров
она читает длины внутренних массивов Clock **проверенной Phaser 4.2.1** через
Reflect/unknown; эти данные не используются для управления игрой.

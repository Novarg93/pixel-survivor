# PixelLab AI — одобренные фаербол и метеорит

По прямому запросу пользователя сделаны **настоящие AI-генерации PixelLab**.
После просмотра пользователь одобрил интеграцию; эти AI-кадры уже в игре.
[Открыть viewer.html](viewer.html) двойным кликом или
через локальный Vite: `/art/generated/mage-spells-pixellab-ai-v1/viewer.html`.

Спрайты:3задания **create_image_pro_flash** (фаербол, метеорит, подсветка).
Движение:5заданий **animate_image_pixminimax** (полёт/попадание обоих и свет).
Дополнительный вариант удара метеорита:1задание **animate_image**.
Итого9AI-заданий,25подписочныхгенераций; баланс уменьшился на25, денежные
кредиты не списывались. Все результаты сохранены в галерее PixelLab и локально.
Промпты/seeds/receipts/results/balances находятся в `source/`.

Общая стилевой reference — точный96²crop принятого мага. Прежние программные
фаербол/метеорит не подавались как входные картинки. Они и Ash Warden показаны
в демо только для сравнения. Арт-стиль задан палитрой, крупными кластерами,
сдержанной яркостью и небольшим размером. Направление падения≈49° согласовано
с осью хвоста новой AI-модели; тот же угол теперь применяется в игре.

## Файлы и подготовка

- `raw/`:57оригинальных PNG —3модели и6анимаций по9кадров.
- В каждом клипе0 — входная AI-модель,1–8 — результаты анимации PixelLab.
- `prepared/`:6PNG-листов и contact sheets,6GIF и6Aseprite, без перерисовки.
- Flight GIF играет1–8 без повторного input0. Попадания/свет играют0–8.
- Preview timings80мс/кадрflight/light,70мсimpact — выбор темпа демо, а не
  тайминг изAPI. PixelLab вернул последовательности PNG без длительностей.
- RGB/RGBA всех54кадров в PNG-листах побитово совпадают с raw. PixelLab
  нормализовал RGB только под прозрачной альфой input0; видимые пиксели и альфа
  входных моделей сохранены. Исходные ответы провайдера не переписывались.
- Свет — отдельный AI pass на чёрном фоне, показан через Screen сopacity0.4;
  перед падением проигрывается в обратную сторону, после — прямое затухание.
  Прозрачная RGBA-подсветка вместо этого не выдаётся за результат генерации.

Оба варианта meteor-impact доступны в инспекторе. Первый дал огненное кольцо,
поэтому заказано уточнение с серыми осколками. У второго всё ещё есть короткая
оранжевая дуга в ранних кадрах; финальный кадр полностью прозрачен. Пиксели
не удалялись локальной маской. Свет заканчивается равномерным почти чёрным
RGB(3,2,2), а не точнымRGB0. Первый вариант удара сохранён для сравнения.

## Проверки

`manifest.json` содержитjob IDs,charges,anchors,raw SHA256 и pixel SHA256.
В `source/protected.json` зафиксирован401существующий файл игры/прежнего арта.
Первый запуск `node scripts/verify-pixellab-spell-review.mjs` подтвердил их
неизменность и отсутствие добавлений/удалений в src/public до разрешённой
интеграции. Сохранённый protected-verification.json — историческое свидетельство;
повторять старый preview-only verifier после интеграции не нужно. Это проверка рамок
поручения, а не постоянный запрет на последующую разработку игры.

Тесты:unit `pixellab-spell-review.test.ts`,browser `pixellab-spell-review.spec.ts`.
Демо проверено HTTP/file://,1280/390/844,пауза/кадры/фон/масштаб/ссылки,
reduced-motion и отсутствие внешних запросов. Canvas PNG в `screenshots/`.

Повторная сборка из уже скачанных результатов:
`node scripts/build-pixellab-spell-review.mjs`.
Повторная загрузка сохранённых jobs без новой генерации:
`node scripts/collect-pixellab-spell-review.mjs`.
Aseprite export:localbatch/source/export.lua, как записано в отчёте.
`prepare-pixellab-spell-review.mjs` не требуется повторять:он создаёт исходный
baseline и стилевой crop, поэтому не запускайте его поверх проверки завершённого
поручения. Полный отчёт: `docs/art/PIXELLAB_MAGE_SPELLS_AI_V1.md`.
Интеграция: `docs/art/PIXELLAB_MAGE_SPELLS_RUNTIME_V1.md`.

# Подключение готового бега Mage V2

## Источники и направления

Принятые три демо из `art/main-hero-mage-v2/animation/runing/` подключены к игровому
движению вместо Walking V2. Кадры, палитры, прозрачность и отбор стадий перенесены
точно из manifest демонстраций; исходники и экспорты viewer не перезаписываются.

| Движение | Источник | Отражение |
| --- | --- | --- |
| S, SE, E | south / передний | нет |
| W, SW | south / передний | по X |
| N | north | нет |
| NE | north-east | нет |
| NW | north-east | по X |

SE/SW продолжают южную схему; это оставшиеся диагонали восьминаправленного управления.

| Набор | Разгон | Повтор | Завершение |
| --- | --- | --- | --- |
| south | start1–13, 1300 мс | loop4–11, 720 мс | stop4–13, 1000 мс |
| north | north1–3, 300 мс | north4–9, 540 мс | north10–13, 400 мс |
| north-east | start/end1–5, 500 мс | loop5–10, 540 мс | start/end10–13, 400 мс |

Атлас `public/assets/hd/mage-run-v2/atlas.png/json`: 59 кадров, 768×768,
2359296 RGBA bytes, NEAREST. Размер в мире берётся из принятого Idle V2:
46.35814889336016 на холст96×96. Pivots: south46/84, north48/83, NE46/83;
зеркало отражает также pivot и кисть. Коллайдер и скорость World не меняются.

## Поведение

`MageRunningAnimation` использует время симуляции для разгона/завершения.
Повтор шага следует фактическому пройденному расстоянию / 135, поэтому haste,
изменение скорости и analog меняют темп ног. Начало движения и физическая
остановка остаются немедленными; переходы являются только представлением.

Разгон входит в выбранную для демо фазу: south11, north4, NE10. Поворот сохраняет
долю фазы и переводит её между длительностями наборов. Разгон не повторяется
при каждом повороте или касте. При отпускании выбирается близкий кадр завершения:
для бега — из первой половины хвоста, для короткого разгона — из всего хвоста.
Это позволяет короткому нажатию вернуться к стойке без полного бега на месте.
Повторное нажатие во время завершения сразу возвращает подходящую фазу цикла.

Pause замораживает обе анимации. RunId/меню/смерть/ultimate lock очищают часы.
Blink displacement ограничивается прежним пределом косметического travel.
Idle и Death используют прежние принятые ассеты. Ключ `pose.walk` сохранён как
диагностика независимого счётчика расстояния; активная текстура — mage-run-v2.

## Каст на ходу

Нижний слой берётся из нового бега и его текущей стадии. Проекция ног соответствует
торсу каста: south, north или north-east, включая зеркальный NW. Фаза переносится
между проекциями по их длительностям. Каст и его release/cooldown/damage сохраняют
независимые часы; при физической остановке показывается цельный стоящий каст.

Новая регистрация содержит150anchors:91cast+59run. Разрез y61 и handBottom59
сохранены. Текстура masked upper остаётся768×412 /1265664RGBA bytes; pixel mask
и исходные касты не перерисовывались. Тёплые пиксели поднятых ботинок ниже y63
не считаются кистями. Кисть для прерванного жеста берётся из видимой кожи кадра;
когда она полностью скрыта плащом — из базовой стойки того же набора, что явно
помечено `handVisible:false` в manifest. Это только visual muzzle fallback.

Используется прежний один pooled upper Image, без новых timers/listeners.
`destroy()` очищает crop, Image и часы. Walking V2 остаётся архивным ассетом,
но больше не запрашивается при загрузке игры; число запросов заменённого атласа то же.

# Audio MVP — проверка

2026-11-03, `feature/audio-mvp`, локальная база `3e5febf`.
План: `PIXEL_SURVIVOR_AUDIO_MVP_PLAN.md`. Статус: техническая часть A–E
проверена; готово к пользовательскому прослушиванию.

## Реализовано

`src/game/audio/`: типизированный каталог, контроллер приоритетов/лимитов,
адаптер Phaser Web Audio, наблюдатель игровых событий, оригинальный PCM-синтез.
Один AudioContext принадлежит Phaser 4.2.1. Используются его `context`,
`destination`, cache.audio, проверенные в установленном исходном коде Phaser.
Нет новых AudioContext на рестартах, сетевых аудиофайлов или middleware.

- Master, Music, SFX, mute в существующих настройках. UI следует SFX ×0.8,
  окружение следует Music ×0.55. Старый профиль версии 2 поддерживается:
  новые поля необязательные, старые рекорды не меняются.
- UI start/select/upgrade/pause/gameOver; hurt/death, Blink/Dash;
  XP/heal/buff/artifact; boss arrival/charge; Guardian awaken/laser/meteor.
- Mage: Fireball cast/impact, Frost Nova, Lightning, Armageddon impact, Shield.
  Warrior: Cleave swing/impact, Whirlwind, Slam, Bladestorm, Iron Skin.
- Раздельные восьмисекундные окружения Grove/Dark Forest, оригинальная
  разреженная музыкальная петля 16 секунд. Переход биома меняет только окружение.
  Дополнительные удары Armageddon используют реальные события и уменьшенный gain.

## Жизненный цикл и изоляция

World публикует ограниченные нейтральные уведомления через `events/gameFeedback.ts`
без импорта звуковых модулей. Вставки World/tickAbilities/loot только уведомляют
представление; бой, HP, спавн, награды, коллизии и cooldown не меняются.
Вариативность звука использует отдельный seeded RNG.

Эталон теста balance-hotfix хранится в `tests/fixtures/balance-hotfix-baseline.json`,
чтобы проверка не зависела от игнорируемого каталога docs. Побайтное совпадение
со старым JSON проверено: SHA256 `2e6547f3a22fe3f68f18b479ad98ca0e5ee6fa7e91898bc47f85fbcc91e2f315`.

До доверенного pointer/key жеста источники не стартуют. Menu без фоновой музыки.
Pause/upgrade останавливают фон с fade; blur/hidden немедленно очищают источники.
Focus самостоятельно не продолжает забег. GameOver выключает фон и один раз
играет death/sting. Новый run очищает очередь/rate limits; отложенный UI старого
run не звучит после unlock. Shutdown удаляет DOM/bridge подписки и аудиоузлы,
общий контекст и кеш остаются в собственности Phaser.

Лимиты: 12 one-shots (до 10 SFX, 2 UI), до 3 loop источников с учётом crossfade.
XP объединяется и ограничен 7 plays/s. Hurt/death и опасные события приоритетны.
Отсутствие Web Audio или ошибка выделения PCM оставляют игру работоспособной
без звука. Неудачный ресурс не генерируется повторно каждый кадр; кодеки не нужны.

## Ресурсы и происхождение

Все **26 ресурсов** (23 патча +3 петли) программно созданы для Pixel Survivor
в `catalog.ts`/`synthesis.ts`. Сторонних сэмплов/мелодий нет; атрибуция третьих
лиц не нужна. Ресурсы предназначены для распространения с проектом.
Манифест длительностей/peak/RMS/размеров: `audio-mvp/ASSET_MANIFEST.json`.

PCM mono, 22050 Hz, Float32: **3 574 752 байта** полного каталога (<4 MB),
генерация ленивая с кешированием. Отдельные сетевые аудиоресурсы: **0 байт**.
Полный app JS: 270.60 kB / gzip 106.29 kB; Phaser: 1387.44 kB / gzip 371.54 kB.
Это размеры целых чанков, не размер одного аудио. Предупреждение Vite о размере
Phaser chunk сохранено.

## Ручное прослушивание и отложенное

Локальные WAV для быстрой проверки: `audio-mvp/sfx-preview.wav` (патчи по порядку
каталога с шагом 1 секунда) и `audio-mvp/underscore-grove.wav` (музыка + Grove).
Они не входят в runtime bundle. Художественная приёмка не выполнена.

- [ ] Несколько минут Mage/Warrior: разборчивость атак, hurt/death, подборов.
- [ ] 100–150 врагов: комфортная громкость и различимость boss/Guardian.
- [ ] Armageddon V: ритм трёх ударов, отсутствие чрезмерного суммирования громкости.
- [ ] Наушники/динамики/физический телефон: unlock, петли, комфорт громкости.
- [ ] Master/Music/SFX/mute, пауза/возврат: субъективно ожидаемое поведение.

Дополнительный музыкальный слой босса и индивидуальные звуки обычных мобов
отложены. Физические устройства и другие браузеры не проверялись.
Следующий шаг — пользовательское прослушивание: `http://127.0.0.1:5199/`.
Commit/push/merge/deploy и новые done-маркеры не выполняются.

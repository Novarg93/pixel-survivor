# Ash Warden — простой South Basic Melee, pilot 02

2026-11-06, main. Подготовлен новый **South-only кандидат: 8 кадров, 650 мс**.
Меч проходит из исходной нижней левой диагонали через пространство перед боссом
в правую сторону и возвращается через две промежуточные позы. Overhead, thrust,
lunge, шаг вперёд, усиление клинка и VFX отсутствуют.

**Художественная приёмка: пока не пройдена полностью.** Траектория, сохранность
меча и короткий возврат стали заметно чище предыдущего RD draft. Но на увеличении
локти/предплечья ещё выглядят как шарнирный rig, а восстановленная под руками
часть кирасы проще исходной брони. На кадрах 3–5 контакт кистей с рукоятью
геометрически сохранён, однако разделение двух перчаток требует ручной оценки.
Это кандидат для просмотра, не approved production-анимация. Остальные направления
не создавались; доработки и дальнейшие атаки автоматически не продолжаются.

## Метод и исходники

Основа — принятая `art/generated/ash-warden-directions-v1/bases/south.png`,
сохранённая без изменений как `source.png` в новом каталоге
`art/generated/ash-warden-basic-melee-south-02/`.
Новых генераций RetroDiffusion, PixelLab или других генераторов **нет**.
Предыдущие RD action-кадры используются только для comparison, не для сборки.

Это локальный пиксельный rig из принятого RD-персонажа:

- Меч, гарда, рукоять и обе исходные кисти образуют один жёсткий узел.
  Он перемещается и вращается nearest-neighbor, без изменения масштаба.
  Кисти отдельно не интерполируются и не перескакивают между руками.
- Плечо/локоть/предплечье обеих рук меняют положение. Исходные фрагменты брони
  поворачиваются как жёсткие пластины; соединения заполняются тёмными суставами.
  Есть небольшой перенос кирасы на 1 px. Корпус не заменён только вращающимся мечом.
- За исходным мечом/руками один раз восстановлены скрытые поверхности кирасы
  и левого наголенника цветами исходной палитры. Это авторская локальная
  обработка, а не незаявленный результат RD; упрощённая кираса остаётся дефектом.
- Маска меча уточнена по фактическим границам: неподвижный след старого клинка
  удалён. Слои, маски и исходный код сохранены для воспроизведения.

Кадры 0 и 7 пиксельно совпадают с принятой статичной базой. Шлем/визор не меняются,
ветви и стопы зарегистрированы на исходных местах. Меч в кадрах 2/6 частично
перекрывает левую стопу: 35 отличающихся пикселей в контрольном ROI — это
перекрытие передним клинком, не перенос стопы. Высота общей bbox меняется
из-за меча перед персонажем, по ней кадры не масштабировались.

Холст **192×192 PNG RGBA**, common pivot **(96,154)**,
world scale **0.6548310811**, как у Directions V1. Масштаб тела около 2.73 Mage
наследуется от принятой базы. Все 44 цвета взяты из неё. Новых цветов,
полупрозрачных краёв и размытого масштабирования нет.

## Тайминг и события

| Кадр | Длительность | Поза | Поворот узла относительно idle |
| --- | ---: | --- | ---: |
| 0 | 80 мс | Исходная стойка | 0° |
| 1 | 70 мс | Минимальный windup | +6° |
| 2 | 70 мс | Начало sweep | −22° |
| 3 | 60 мс | Проход перед корпусом | −56° |
| 4 | 90 мс | Hit, противоположная сторона | −94° |
| 5 | 80 мс | Первый возврат | −60° |
| 6 | 90 мс | Второй возврат | −20° |
| 7 | 110 мс | Исходная стойка | 0° |

Итого **650 мс**: до активной фазы 220 мс, активная фаза 150 мс,
возврат 280 мс. Нет прежней выдержки нейтрального кадра на 370 мс.
Меч проходит по нижней фронтальной дуге; его кончик всё время ниже кистей.

В `events.json`: attackStart и directionLock 0 мс; windupEnd 220 мс / кадр 3;
hitFrame **280 мс / кадр 4**; activeEnd 370 мс / кадр 5;
recoveryEnd 650 мс. Направление [0,1] фиксируется один раз при старте,
hit отправляется один раз на attackInstanceId. Окно визуального стыка
с locomotion 540–650 мс, выход после 650 мс. Радиус попадания не назначен.
Это визуальные метаданные: урон, AI и игровые хитбоксы не менялись.

## Проверка критериев

| Критерий | Результат |
| --- | --- |
| Цельный широкий меч | Сохранён как один жёсткий исходный слой, без морфинга |
| Один grip / две кисти | Взаимное положение фиксировано; визуальная раздельность кистей на 3–5 ещё требует приёмки |
| Простой фронтальный cleave | Читается на desktop/mobile, без высокого замаха и вертикального smash |
| Возврат в исходную стойку | Есть последовательность 4→5→6→7; конечный кадр точный idle |
| Шлем, ветви, масштаб, pivot | Стабильны; исходники и принятые клипы не изменялись |
| Естественность рук / броня под хватом | Остаются механические локти и более плоская восстановленная кираса |
| Отличие от Infernal Great Cleave | Меньшая амплитуда, 650 мс против исходных 1800 мс, без overhead и VFX |

Технический аудит пройден. Полную художественную готовность не подтверждаю:
следующая правка — силуэты локтей и ручная фактура открывшейся кирасы в 3–5,
затем повторная оценка двух перчаток в игровом масштабе. Новый случайный дизайн
или дополнительные направления для этого не нужны.

переходы Idle→Melee→Idle, один hit на переход и два hit на два цикла,

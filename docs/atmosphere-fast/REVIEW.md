# Заметная смена атмосферы и ранний ультимейт

2026-11-05, main. Текущая итерация после ручной приёмки.

| Порог | Переход |
| --- | --- |
| 05:00 | Normal → Darkened, завершение05:02.5 |
| 10:00 | Darkened → Creepy, завершение10:02.5 |
| 15:00 | Creepy → Burning, завершение15:02.5 |

До порога предыдущая фаза сохраняется полностью. После порога весь её tint,
veil, fog, vignette, glow и embers смешивается за2,5s по smoothstep.
Карта, исходные палитры, World/layout, HUD, бюджеты и очистка прежние.

Ультимейт предлагается на повышении уровня при обоих условиях:
elapsed≥300s и уровень карточки≥30, включая30. До5:00 даже высокий уровень
не даёт ульту; после5:00 уровень29 тоже не даёт. Если30 достигнут раньше5:00,
предложение придёт при следующем повышении после порога. Первый заряд10/10,
последующие10успешных Blink, урон и длительности сохранены.

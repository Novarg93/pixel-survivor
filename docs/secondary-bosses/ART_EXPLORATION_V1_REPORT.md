## Границы этапа

Работа выполнена в текущей `main` после реализации Ash Warden Gameplay Integration V1. Состояние рабочей копии записано в `initial-worktree.json`. На протяжении этого художественного эксперимента защищены хешами **2277 файлов**: `src`, `public`, принятые `ash-warden-*` пакеты и конфигурация проекта. Итоговая сверка: **0 изменений** этих файлов.

Новые модели не загружаются игрой. FinalEncounter, текущий Ash Warden, обычные Boss/Guardian AI, HP, rewards, орбы, Enrage, спавны и атласы не изменялись на этом этапе. Guardian Shield, реализованный предыдущим интеграционным этапом, остаётся без изменений. Commit, push, deploy и новые ветки не выполнялись.

Изучены существующие определения врагов, BossSystem / ChargeBoss / EclipseBoss, RareGuardianSystem, GuardianOrbs, атласы и художественный workflow Ash Warden. Использованы его PNG/GIF utilities и подход к декодированию через Chromium ImageDecoder; текущий Grove renderer переиспользован для сравнительного фона, без его копирования в игровую архитектуру.

Внутри каждого из трёх боссов все четыре теста используют одну выбранную модель. Другие направления, Idle/Walk/Death не создавались.

## Teleport: честное разделение результата и композиции

Во всех четырёх исходных RD-клипах персонаж остаётся видимым. Это существенное ограничение, а не скрытый успешный результат. Оригинальные GIF и PNG не менялись.

Для review подготовлена отдельная локальная presentation-композиция поверх этих реальных жестов:

- A: пиксельная ordered-dither dissolve-маска, пустой кадр 6; перенос в preview на 900 мс.
- B: короткий hard blink, пустые кадры 4–6; перенос на 600 мс, восстановление с кадра 7.
- `presentation/frames`, `preview.gif`, `departure.gif`, `arrival.gif`, metadata и подписанный composition contact sheet сохранены отдельно.
- Отдельные маленькие rune/astral VFX и видимость тела отключаются переключателем **«Отдельные VFX»**. В выключенном режиме viewer показывает нетронутые исходные жесты и не переносит видимого персонажа.
- Координаты никогда не зашиты в PNG. Между двумя точками перемещается только preview-instance во время невидимости. Future World relocation и homing logic не реализовывались заново.

Эти производные материалы явно помечены как локальная сборка, а не новые генерации. Для окончательной игры потребуются принятые timings исчезновения/появления и проверка безопасного interruption contract.

## Генерации и расходы

Основной стиль моделей: `rd_pro__default`128. Движения: `rd_advanced_animation__custom_action`192 с реальным input PNG и `frames_duration=12`. Для одной неудачной диагностической попытки использовался доступный `attack`. Перед каждым запуском проверены balance, active jobs и estimate; максимум2 plan jobs одновременно.

Фактически:

- **26 запросов**: 9 статичных и17 анимационных запусков.
- **23 технически успешных job**: один из девяти статичных результатов оказался почти пустым (2 видимых пикселя), сохранён как неудачный исходник; одна контролируемая замена дала пригодную модель A. Итог —8 моделей и14 движений.
- **3 сбоя502 без денежных списаний**: в первых трёх motion requests ошибочно передано150 как `frames_duration`. Причина найдена сравнением с успешными запросами проекта; параметр выбирает количество кадров, не миллисекунды. Исправленные однократные попытки находятся в `attempt-2`, failed metadata сохранены. Автоматических платных повторов после timeout нет.
- Максимальная оценка одного реально запускавшегося запроса —**$0.25**, ниже разрешённых$0.50.
- Баланс **$10.00 → $9.50**, фактически списано **$0.50**, сумма billing charges совпадает с разницей баланса. Лимит$5.00 соблюдён, резерв$5 не затронут.
- Starter **44% → 0%**: израсходованы44 отображаемых процентных пункта. API отдаёт целые округлённые проценты, поэтому это точное сравнение показаний, а не точное число внутренних токенов.
- Активных API jobs по завершении —**0**. Новых вызовов больше не планируется. PixelLab/image_gen не использовались, тариф/подписка не менялись.

При скачивании один частичный GIF был сохранён отдельно как `incomplete-transfer.bin`; полный результат восстановлен из того же job с проверкой SHA-256. Нового платного вызова для скачивания не было. В manifest нет API-ключей или подписанных приватных URL.

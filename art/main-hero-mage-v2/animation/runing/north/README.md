# Mage V2 — северный бег

Открыть `viewer.html` рядом с этим файлом. Он переводит в общий viewer с выбранным
северным видом; работает и через file://, и по HTTP. В общем viewer можно
переключаться между передним и северным видами без перезагрузки страницы.

Исходник `north.png` содержит 13 кадров 96×96 в сетке 4×4. Кадры считаются
слева направо, сверху вниз, начиная с 1.

| Стадия | Исходные кадры | Темп | Длительность |
| --- | --- | --- | --- |
| Run start | 1–3 | 100 мс/кадр | 300 мс |
| Run loop | **4–9** | 90 мс/кадр | **540 мс** |
| Run end | 10–13 | 100 мс/кадр | 400 мс |

В позах4 и10 совпадает фаза шага, поэтому в повторе достаточно одного полного
шага4–9. Стык повтора9→4 возвращает героя в ту же фазу, что переход9→10
в исходнике. Начало1–3 входит в4, завершение выходит из9 в10. Стойки1/13
не попадают внутрь повторяемого бега. При раннем отпускании команды сначала
заканчивается текущий шаг, затем показываются10–13; новые кадры не вставляются.

Пиксели и прозрачность всех исходных поз сохранены точно. Все13кадров доступны
в режиме «Исходный лист». Pivot48/83 фиксирован для всех стадий, нижняя точка
базовой стойки — y82. Фон прокручивается вниз для оценки бега на север.

PNG не задаёт тайминги: выбранные100/90мс служат демонстрации. Видимые колебания
ткани и позы сохранены из пользовательского источника. Подключение к игровому
движению и скорости — отдельная задача.

Экспорты: `prepared/run-start.*`, `run-loop.*`, `run-stop.*` и полный
`run-raw-loop.*` (PNG/GIF). `animation.json` сохраняет исходные номера кадров,
тайминги и SHA256. Пути внутри manifest заданы относительно общего каталога runing/.
Builder из корня проекта: `node scripts/build-mage-running-north-demo-v2.mjs`.

Проверки: все26экспортированных поз совпадают с исходными RGBA; северный исходник
и13прежних исходников/экспортов не изменились, повторная сборка10выходных файлов
идентична. Проверены число кадров и тайминги всех4GIF. Девять unit-тестов viewer
проверяют пиксели, стадии, раннюю остановку и разбиение времени обоих видов.

Восемь E2E PASS: передний и северный виды, полная последовательность, ручная
остановка, пауза, десять переключений вида, file:// и HTTP. File:// покрыт
на1280×720,390×844 и844×390, все6северных фаз отрисованы на Canvas; браузерных
ошибок и горизонтального переполнения нет. Снимки в `screenshots/` просмотрены.
Первый HTTP smoke обнаружил404 favicon на странице перехода; добавлена пустая
иконка, повтор8/8 прошёл без фильтрации ошибок или ослабления assertions.

Финальные typecheck/lint/build PASS; полный unit suite —117файлов/959тестов
с --maxWorkers=2. Полный игровой E2E suite не запускался.

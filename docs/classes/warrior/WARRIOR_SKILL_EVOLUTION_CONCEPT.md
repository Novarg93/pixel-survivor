# Warrior — идеи веток развития навыков

V1 · концепт для будущего production. **Не баланс и не реализованные механики.**
Три направления на каждый из шести принятых базовых навыков. Сначала выбрать
роль ветки, затем её визуальный мотив; не складывать все варианты в один эффект.

| Навык | Ветка | Игровая идея на будущее | Как развивается визуальный мотив |
| --- | --- | --- | --- |
| Cleave | Широкий размах | Больше фронтального охвата | Удлинить концы единого полукруга A; не превращать в круг Whirlwind |
| Cleave | Тяжёлый скол | Реже, но сильнее первый удар / пробитие брони | Толще рабочая грань, 2–3 крупных скола из B; короткий тяжёлый контакт |
| Cleave | Рваная рана | Небольшой урон со временем по задетым целям | Узкий тёмно-бордовый разрез на цели, не красная заливка всей дуги |
| Whirlwind | Стягивающий вихрь | Короткое слабое притяжение обычных врагов; боссы устойчивы | Концы трёх дуг B загнуты внутрь; пустой центр сохраняется |
| Whirlwind | Стальной заслон | Короткая защита во время вращения | Две компактные боковые пластины Shield A между дугами; без второго купола |
| Whirlwind | Каменная мельница | Дополнительные контакты рядом с героем | На внешней грани несколько крупных каменных сколов; ограниченный след |
| Ground Stomp | Повторный толчок | Второй слабый импульс после основного | Ещё одна разорванная волна из того же узла; не две постоянные окружности |
| Ground Stomp | Раскалывающая пятка | Три направленных трещины вместо равномерного роста радиуса | Укороченный мотив трёх ветвей Earthbreaker; обычный навык остаётся заметно меньше |
| Ground Stomp | Оглушающий упор | Короткий stun обычных врагов; ограниченный эффект на боссах | Крупные плиты B и три коротких ударных зубца у контакта, без звёзд над головой |
| Shield Block | Ответный удар | После блокирования — короткий фронтальный ответ | На стороне принятого удара один стальной клин; не круговая Nova |
| Shield Block | Отражающая грань | Ограниченно возвращает часть снарядного урона | Одна направленная искра от края щита; читаемый угол отражения, без веера частиц |
| Shield Block | Крепость | Дольше удерживает защиту / временный запас прочности | Шире тёмная масса двух пластин A и один дополнительный латунный шов |
| Piercing Throw | Возвратное копьё | После прямого пробития возвращается по отдельному пути | Короткий обратный след с ясным наконечником; силуэт не меняется на круглый щит |
| Piercing Throw | Насквозь | Лучше проходит плотную линию врагов | Более длинное жёсткое древко и узкий светлый контакт на каждой пробитой цели |
| Piercing Throw | Расщеплённый наконечник | После первого контакта — две более слабые ветви | Два коротких расходящихся стальных осколка, ограниченный угол и число |
| Charge | Пролом | Урон по фактически пройденному пути | Семейство A: стальной след и фронтальный серп прибытия; без широкой непрерывной дорожки |
| Charge | Прикрытие | Временный absorb после рывка | Клин B ведёт движение; после прибытия остаются тихие боковые пластины Shield A |
| Charge | Таран | Оглушение в точке прибытия | Прибытие B: упор щитом, три коротких ударных зубца и один каменный разлом |

Ультимейты уже имеют принятые роли: **War Banner** — якорь усиления15с,
**Earthbreaker** — три ветвящихся разрыва/последовательных извержения,
**Spear of Ruin** — тяжёлое пробитие по прямой. В этом этапе для них показаны
статические A/B-концепты, дополнительные деревья улучшений не проектировались.

Общие ограничения будущей реализации: bounded число повторов/осколков,
явная политика иммунитета боссов, отсутствие бесконечного отражения и
многократного попадания одного контакта. Это вопросы следующего дизайна,
а не изменения текущих World/upgrade definitions.

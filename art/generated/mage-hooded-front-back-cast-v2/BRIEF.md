# Mage B — исходная передняя стойка + спина, исправленный cast pass

Последнее уточнение пользователя имеет приоритет над неверно понятым side-only v1.

- **Передняя база** — точный исходный PNG B:
  `art/generated/mage-hooded-cast-v1/source/selected-b.png`.
  Не заменять его новой боковой моделью; сохранить корпус/капюшон/ноги в этой стойке.
- Из передней базы произвести жесты **E, SE, S**. Для **W, SW** точно отразить
  соответствующие E, SE. Корпус ориентирован как исходный B, меняются руки.
- **Задняя база** — тот же B строго со спины, смотрящий на север, без видимого лица.
- Из задней базы произвести жесты **NW, N**; **NE** — симметричный NW.
  Пользователь отдельно подтвердил именно NE, а не строго E, для третьего жеста.
- Получаются восемь направлений целей из двух положений тела, без восьми моделей.
- По6кадров на cast, средняя детализация, длинная мантия и исходная палитра;
  общие жесты без встроенных spell VFX. Новые source/poses только через PixelLab;
  зеркала, упаковка и точная локальная пиксельная очистка — без новой генерации.
- Исходники/rigs/prompts/seeds/jobs/billing сохраняются. Production и прежний
  принятый арт не изменяются. Отдельный viewer должен показывать базу рядом с каждым
  действием, чтобы не скрыть ошибочный поворот корпуса.

Проверять: соответствие body stance базе, вид со спины без лица, читаемость жеста
в каждом направлении, стабильность ног/головы, точность зеркал, alpha/bounds/CRC,
шесть поз, timings/GIF/atlas, Canvas screenshots desktop/mobile, file/HTTP,
pause/frame-step/target selection, SHA256 прежних файлов и npm run check.

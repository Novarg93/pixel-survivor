# Mage: старт, непрерывный бег, остановка

2026-11-08. По запросу пользователя Walk убран из активной анимации мага.
Раньше весь16-кадровый ролик Run повторял разгон и возвращение в стойку.
Теперь отдельно проигрываются старт, постоянный цикл и остановка.

PixelLab MCP PixMiniMax:8 успешных jobs, каждый8 generated frames плюс входной
кадр. Вход — четвёртый кадр прежнего Run соответствующей проекции, уже в шаге;
конец закреплён в той же позе. Восьмой сгенерированный кадр почти повторяет
входной и не включён в проигрывание. Получилось8 distinct phases×60ms=480ms,
обычный forward loop. Boundary pixel delta составляет0.696–1.000 от самого
крупного внутреннего шага, без аномального скачка на замыкании. Все направления
просмотрены на native contact strips и фактических Canvas последовательностях.

Сырьё и квитанции: `art/main-hero-mage/abilities/hero-model/run-cycle-v2/`.
На направление сохранены requests/receipt/result,9rawPNG, contact/audit,
native.png/gif/json. По job receipts списано8 generations (1/job), credits$0;
общий баланс аккаунта не используется для приписывания задаче чужих списаний.
Оригинальная ходьба и прежние полные ролики бега сохранены.

Idle → Start(.16s) → Run(дистанция/135) → Stop(≤.2s) → Idle.
Остановка захватывает показанный кадр и выбирает наиболее близкую исходную
позу из хвоста торможения. Ввод во время stop немедленно возобновляет ближайшую
фазу Run. Повороты не повторяют старт; короткое нажатие завершается коротким
хвостом. Пауза замораживает фазу и часы. Никаких новых игровых задержек,
изменений скорости или скольжения координат не добавлено.

Start/Run/Stop работают как ноги составного каста. После короткого stop опять
возможен цельный каст к цели; до этого верх/низ сохраняют одно направление.
Ультимейты используют прежние анимации/блокировку движения. Shield gesture
по прежнему временно отключён, поглощение и HUD действуют.

Runtime:72clips/799sequence frames,2pages(2048×2048,2048×180),18251776RGBAbytes.

# Mage V2 — бег на северо-восток

Открыть `viewer.html` рядом с этим файлом: он выбирает северо-восточный вид
в общем viewer. Работает напрямую через file:// и через локальный HTTP.
В переключателе «Вид» доступны передний, северный и северо-восточный наборы.

Оба исходных PNG содержат по 13 кадров 96×96 в сетке 4×4. Нумерация —
слева направо, сверху вниз, начиная с 1.

| Стадия | Лист | Исходные кадры | Темп | Длительность |
| --- | --- | --- | --- | --- |
| Run start | run-start-end.png | 1–5 | 100 мс | 500 мс |
| Run loop | run-loop.png | **5–10** | 90 мс | **540 мс** |
| Run end | run-start-end.png | 10–13 | 100 мс | 400 мс |

Из первого листа взяты только начало и хвост движения. Из второго выделен
полный шаг из шести поз: стойки и подготовительные позы 1–4, а также повторный
хвост 11–13 не входят в цикл. Стык повтора — **loop10 → loop5**.

Последняя поза разгона стыкуется с loop10, затем цикл идёт через 5–10.
При запросе остановки заканчивается шаг до loop7, затем показываются
start/end10–13. Такая стыковка использует близкие фазы шага двух генераций.
Пиксели между листами не смешиваются и новые промежуточные кадры не добавляются.

В viewer доступны оба полных исходных листа: «Исходный лист бега» и
«Исходный start/end». Переключение на вид без второго листа возвращает
несовместимый режим просмотра к полной последовательности. Есть пауза,
покадровый шаг, ползунок, темп и ручное управление бегом/остановкой.

Pivot 46/83 фиксирован для всех стадий; RGBA и исходные холсты сохранены точно.
Фон движется влево-вниз, иллюстрируя бег на северо-восток. PNG не содержат
таймингов: выбранные 100/90 мс — темп демонстрации. Изменения мантии и позы
между генерациями сохранены. Согласование с игровой скоростью — отдельная задача.

`prepared/` содержит пять наборов PNG/GIF: три стадии и два полных исходных
просмотра. `animation.json` хранит источник каждой стадии, исходные номера,
тайминги и SHA256. Пути в нём заданы относительно общего каталога runing/.

# Ash Warden SFX — демо для приёмки

[Открыть демо](viewer.html). Выберите дубль №1–4 и нажмите «Все атаки подряд»
либо слушайте отдельные записи. Между атаками в последовательном демо есть
короткая пауза. Номер дубля не является оценкой качества.

Сгенерированы четыре основных промпта A из
[ASH_WARDEN_SFX_PROMPTS.md](../../../docs/audio/ASH_WARDEN_SFX_PROMPTS.md):
Basic Melee, Charge, Flame Strike, Meteor. На каждой ноде стандартные4 дубля,
всего16 MP3 /468628 bytes. Варианты промптов B и дополнительные фазы не
генерировались. Статус: **Awaiting Review**, подключение к игре отсутствует.

- Модель: `eleven_text_to_sound_v2`, `prompt_influence:0.3`, `loop:false`.
- Запрошено:0.6 /0.7 /0.7 /0.8с. Декодировано:0.6 /≈0.68025 /≈0.68025 /0.8с.
- Одна партия генерации,16 успешных результатов. Повторных платных запусков нет.
- Flow: [Pixel Survivor — Ash Warden](https://elevenlabs.io/app/flows/LjY7XGjtTMS1RezHULHp).
- Все `source/*.mp3` — оригинальные байты сервиса, без trim/normalize/transcode.
  SHA-256 и generation IDs сохранены в `generations.json` и `manifest.json`.

Проверено автоматизированно:16/16 декодируются и содержат сигнал;
16 audio controls загружают metadata; последовательное демо воспроизводит
все4 атаки; смена дубля и остановка работают;390px viewport без overflow;
ошибок JavaScript нет. Скриншоты: `review-desktop.png`, `review-mobile.png`.
ESLint скрипта сборки прошёл. Проверка сигнала не заменяет прослушивание:
в10 дублях декодированный peak достигает полной шкалы, доля таких отсчётов
сохранена в manifest. Отсутствие слышимых искажений не утверждается.

Кредиты: предварительная оценка112; сумма `credit_costs` в квитанции запуска36;
сумма `price.credits` в записях результатов≈37.3333. Эти поля сервиса
расходятся, поэтому ни одно не выдаём за проверенное изменение баланса.
Все исходные значения сохранены; отдельная проверка баланса не выполнялась.

`request.json` содержит полные промпты, параметры, IDs и квитанцию;
`verification.json` — проверки плеера; `runtime-verification.json` —
подтверждение неизменности376 файлов `src` и `public`.
Для повторной локальной проверки без генерации:
`node scripts/build-ash-warden-sfx-review.mjs` из корня проекта.

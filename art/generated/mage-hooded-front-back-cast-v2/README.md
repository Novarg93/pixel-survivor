## Кадры и тайминги

Каждый клип содержит 6 различных поз: исходная стойка → подготовка → замах →
выпуск → продолжение → возврат. Первый подготовленный кадр берётся прямо из
соответствующей исходной базы, чтобы начало было именно принятой стойкой.
Зеркальные клипы начинают с её точного отражения.

Длительности: `70, 70, 80, 90, 70, 100 ms`, всего **480 мс**.
Поза выпуска — кадр 3, с **220 мс**. Это предлагаемые art timings для просмотра;
игровые cooldown, targeting и timestamps не менялись.

Canvas каждого кадра — 96×96. Pivot фиксирован для базы и всех её кадров:
front `[46,84]`, north `[48,84]`; зеркальный X равен `96−pivotX`.
Покадрового центрирования по bbox нет. GIF одноразовые. Viewer повторяет клип
после 400 мс в исходной стойке.

## Просмотр

- Слева от анимации показана её настоящая база, справа — каст.
- Есть выбор всех направлений, пауза, скорости ×0.25/0.5/1/2, scrub и frame step.
- В режиме выбора цели щелчок вокруг правого мага выбирает нужный жест и базу.
- Общий лист показывает все 8 выпусков вокруг двух исходных стоек.
- Есть Grove и статичная проверка игрового масштаба рядом с актуальным игровым
  Ash Warden. Композиции явно обозначены как preview, не как интеграция в игру.

В preview всем магам назначена видимая высота нынешнего героя 34.6875 world px,
camera zoom 2. В production scale ничего не записывалось. Выбор жеста дискретный;
непрерывный IK или точные игровые palm origins этой поставкой не заявляются.

## Исходники и воспроизведение

- `source/`: неизменённый front B, новый north и их точные зеркальные копии.
- `raw/`: 30 неизменённых кадров PixelLab, по 6 для E/SE/S/NW/N.
- `prepared/`: 30 исходных поз с канонической стойкой в кадре 0 и 18 зеркальных
  кадров; всего 48 PNG для 8 клипов.
- `generation-manifest.json`: полные prompts, seeds, COCO-18 rigs, source/job IDs.
- `cleanup.json`: точные координаты локальных исправлений. В 5 кадрах удалены
  166 лишних пикселей: отделённые фрагменты и случайно добавленный жёлтый шар с
  остаточными частицами. Цвета кожи/рукава в области шара не удалялись. Raw сохранены.
- `exports/`: 8 GIF, 8 PNG-листов; атлас исходных 30 поз 576×480, JSON. Зеркала
  могут переиспользовать эти текстуры через flipX. RGBA-память атласа: 1 105 920 байт.
- `animation.json`, `viewer-data.js`: связи направлений, баз, зеркал и фаз.
- `frame-validation.json`, `browser-validation.json`, `protected-validation.json`,
  `screenshots/`: проверки и визуальные материалы.

Из корня проекта, без новых запросов генерации:

```sh
node art/generated/mage-hooded-front-back-cast-v2/prepare.mjs
node art/generated/mage-hooded-front-back-cast-v2/prepare-cleanup.mjs
node art/generated/mage-hooded-front-back-cast-v2/build.mjs
```

`validate-browser.mjs` экспортирует `validate(page)` для Playwright. Для MCP его
функции передаются в browser code без `export`; результат сохранён в JSON.

## Проверки и расход

### Исправление S — длина рук

По замечанию пользователя заменены только кадры **3 (выпуск)** и **4 (продолжение)**
клипа S. Прежние руки доходили к коленям. В новых позах локти согнуты, ладони
вынесены перед поясом с сокращением в перспективе. [До/после](repairs/s-arm-length-v1/before-after.png).

Два PixelLab edit-результата сохранены в `repairs/s-arm-length-v1/`. В исходные
кадры перенесена только область рук и восстановленной за ними мантии; голова,
ноги и все пиксели вне прямоугольника `[27,33,65,75]` сохранились точно.
Убраны три одиночные точки на ткани. Исходные плохие кадры и GIF сохранены в `before/`.

`frame-overrides.json` закрепляет замену при каждой сборке. Для её воспроизведения:

```sh
node art/generated/mage-hooded-front-back-cast-v2/compose-s-arm-repair.mjs
node art/generated/mage-hooded-front-back-cast-v2/build.mjs
node art/generated/mage-hooded-front-back-cast-v2/prepare-s-arm-repair.mjs
```

исходники и raw не изменены. Обновлены S GIF/PNG и общий атлас. Повторная проверка
всех 8 GIF и viewer прошла. Прямое открытие S:
`http://127.0.0.1:5173/art/generated/mage-hooded-front-back-cast-v2/viewer.html?direction=s`.

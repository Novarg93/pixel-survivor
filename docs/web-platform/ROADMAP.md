# Pixel Survivor — Web Platform Roadmap

Утверждённая пользователем новая область разработки, 2026-11-14. Исторический
`PLAN.md` описывает автономный offline MVP и не переписывается. Его запреты на
Laravel, аккаунты и онлайн-экономику не распространяются на эту отдельную фазу.
Правила изоляции, качества, сохранения ассетов и запреты commit/push/deploy действуют.

| Этап | Результат и граница приёмки |
| --- | --- |
| 01 — Foundation | Laravel в `apps/web`, официальный Vue Starter Kit, публичный сайт, Contact, стандартная авторизация, кабинет с empty states, настоящая игра `/play`, контракты и проверки. Только этот этап реализуется текущим заданием. |
| 02 — Account & Character Progression | Серверные уровни аккаунта/Mage/Warrior 1–10, версионированные таблицы наград и бонусов, идемпотентная обработка проверенного результата; интеграция только после тестирования run lifecycle. |
| 03 — Inventory & Wallet | Общий инвентарь, кредитный ledger, атомарные покупки за кредиты, ручная активация XP Boost, восстановление после сбоев. Без платёжного провайдера. |
| 04 — In-run Items & Revive | Пауза, серверные consume receipts, состояние pending revive до окончательного завершения; устойчивость к повторам и потере сети. |
| 05 — Commerce | Только после отдельного выбора провайдера, цен, политики возвратов и утверждения legal: платёжные webhooks, сверка, возвраты. Секреты исключительно в окружении. |
| 06 — Global Leaderboard & Operations | Один общий рейтинг, история расходников, проверки и очередь review, Filament 5 для уполномоченных операторов. Никаких обещаний полного отсутствия читов. |

Не переходить к следующему этапу автоматически. Отдельные новые механики,
монетизация, административная панель и публикация не разрешены фактом создания
roadmap. Боевой баланс и ассеты не меняются в Phase 01.

Definition of Done Phase 01: локальный Laravel запускается; `/`, `/faq`, `/contact`,
legal drafts и `/play` публичны; регистрация/вход/выход/reset/verification работают;
`/dashboard` защищён; Contact валидируется/ограничивается/сохраняется; desktop/mobile
landscape Phaser проверены с Canvas screenshots; game check, Laravel tests,
web frontend build и репрезентативные Playwright smoke пройдены, ограничения записаны.

E/SE — направленные жесты фронтального корпуса; north/back-NE дополняют бег.

не объявляются новыми независимыми профильными моделями.

## Навыки и качество выбранных кадров

Для каждого из9принятых навыков есть композит модели и PixelLab VFX,
переключатели «только модель / только VFX / оба». ChargeA/B показывает
отдельно start → travel → arrival. Отдельные front-жесты дополняют общий
набор направленных атак; полный directional-pass каждого спецжеста не заявляется.

- **CleaveA:** анимированный фронтальный серп с кратким светлым рабочим краем.
- **WhirlwindA:** цикл двух разреженных дуг и полный поворот модели.
- **Ground StompA:** поднятая нога/контакт и движение каменных сколов.
- **Shield BlockA:** защитная стойка, щит и тихий цикл боковых пластин.
- **Piercing ThrowA:** подготовительная поза с настоящим копьём, бросок,
  отдельный анимированный полёт.
- **ChargeA/B:** общий физический жест и все6принятыхVFX-компонентов.
- **War BannerA:** постановочный жест без постороннего предмета,
  анимированное полотнище с шевроном и спокойная зона.
- **EarthbreakerA:** тяжёлый удар и анимация трёх разветвлённых путей/камней.
- **Spear of RuinB:** тяжёлый бросок и принятое таранное копьё с прямым следом.

Первые жесты throw/ruin сохраняли меч вместо копья. Они оставлены как
отвергнутые источники; новые жесты созданы с отдельной spear-ready позы.
Первый banner-жест придумывал голубой шест, второй — голубую энергию.
Выбран **третий проход через PixelLab PixMiniMax** с явным описанием
физического пустого кулака; этих посторонних эффектов в выбранном жесте нет.
Остальные анимации выполнены PixelLab animate_image, базы — edit_image_pixen.

Выбор кадров полностью прозрачен в `source/selection-policy.json`:

- У цикла War Banner исключены из playback исходные3/4 с чрезмерным белым
  sweep; все9оригиналов остаются в raw, atlas и листе кадров.
- У жеста Ruin исключён source6: вылетающее копьё касается границы128px
  (6краевых пикселей). Тело не обрезано; снаряд показывается отдельным VFX.
  Оригинальный source6 сохранён побайтно. Выбранный playback не имеет
  краевых пикселей; этот факт не подменяет наличие исходного дефекта.

Атлас сохраняет **точные RGBA всех339выбранных исходных cels**, включая
исключённые из playback; локальной перерисовки, palette-reduction,
размытия и синтеза промежуточных кадров нет. Зеркала/поворот/траектории
viewer — обычная компоновка готовых изображений, не дополнительные AI-кадры.
Настройки контакта/скорости — временная шкала приёмки, не gameplay-события.

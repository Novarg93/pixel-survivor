# Phase 2 — расширение игрового процесса

Продолжение существующего MVP. Старые задачи и маркеры 00–11 сохраняются. Phaser владеет временем, Vue — оболочкой. Seeded RNG, UI до 10Гц, caps: 150 обычных врагов / 3 босса / 96 снарядов / 240 XP / 96 эффектов. Новые длительные зоны делят бюджет 24 с отложенными ударами.

| Этап | Работа | Критерий проверки |
|---|---|---|
| 12 | Частота spawn ×1.3, без долга после cap/pause | Старый/новый World с одинаковым seed, прирост около 30%, cap/refill/pause tests |
| 13 | Анимированные hit/death/элементальные эффекты, интенсивность/цифры | Ограниченные пулы, настройки сохраняются, telegraphs не зависят от настройки |
| 14 | Пять поведенческих эволюций | Eligible карты, уникальные 3 выбора, пределы и отсутствие рекурсивных procs |
| 15 | Rush charger, splitter, frenzy/shielded/volatile | Додж-окна, дети без размножения, общий cap, expiry/cleanup |
| 16 | Третий босс — Хранитель затмения | Две HP-фазы, кольца с безопасными промежутками/метки, owner cleanup, прежний boss cap |
| 17 | Warrior и 5 самостоятельных умений | Общий World, отдельный каталог/улучшения, выбор персонажа, reset |
| 18 | Dark Forest | Своя палитра/деревья/тайлы, детерминизм, bounded chunks, выбор карты |
| 19 | Урон по умениям и подробный итог, QA | check/build/dev+production E2E, обе карты/герои/mobile, minute peak smoke, просмотр PNG |

После каждого этапа: `npm run check`, соответствующие тесты, PROGRESS/DECISIONS; только затем NN.done. Старый run-stages.ps1 не запускается. Выполнение в текущей сессии не требует отдельного runner. Полные ручные длительные забеги и реальные мобильные устройства отмечаются отдельно от автоматизации.

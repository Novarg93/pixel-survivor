## Импорт утверждённого East

Оба обязательных файла найдены до любых платных вызовов:

- `incoming/east/east-walk.gif`:295571байт, native768×768;
- `incoming/east/east-walk-spritesheet.png`:368733байта,3072×2304, сетка4×3.

GIF декодирован существующим подходом проекта: Chromium `ImageDecoder` с реальными
GIF-кадрами и их durations. Получены **12×150ms=1800ms**,6.6667FPS. Фон прозрачен,
partial alpha0, edge pixels0 во всех кадрах. Размер каждого кадра остаётся768×768.
GIF в `east/east-walk.gif` и копия в `east/originals/` побайтно совпадают с incoming.

Во всех12GIF-кадрах каждый блок4×4 содержит одинаковый RGBA. Это точное целочисленное
увеличение исходной сетки192×192. Поэтому:

- канонические East/West PNG и GIF **сохранены в768×768**;
- logical canvas Viewer —192×192 с единым фиксированным коэффициентом0.25;
- native pivot —(384,616), logical pivot —(96,154);
- world scale логических пикселей —0.6548310811;
- фактический масштаб native-texel в World —0.25×0.6548310811;
- индивидуального центрирования, bbox fitting, переменного масштаба или перерисовки нет.

GIF и входящий PNG НЕ пиксельно одинаковы. Проверка всех12×12соответствий нашла
для GIF0..11лучшим PNG-кадр с тем же индексом0..11: порядок одинаковый. Alpha
совпадает точно во всех кадрах, но RGB-различия составляют от12000до47232native
пикселей на кадр; максимальная разница отдельного RGB-канала по кадрам —от1до75.
Это различие цветов/деталей сохранено, а не молча смешано. Входящий PNG остаётся
отдельным quality reference; Viewer имеет специальный режим «East GIF / входящий PNG».
Все канонические East-кадры извлечены только из GIF.

Полная проверка: `east/import-validation.json`. Последовательность PNG/West
никогда не собиралась из более красивых отдельных ячеек входящего sheet.

Из каждого GIF извлечены полные RGBA PNG с исходным расположением. Edge/partial

South bounds по кадрам: xmin37..37, xmax141..144, ymin31..36, ymax153..155.
North: xmin60, xmax167, ymin34..35, ymax153. Это записанные исходные изменения RD,
не исправленные индивидуальной центровкой. Масштаб тела сопоставим с East после
одного доказанного4×presentation factor: около120–124logical px по высоте.

`animation-metadata.json` хранит frameCount, originalFrameDurations,
playbackDuration, native/logical canvas и pivot, scale, visualFacing/combatFacing,

West —front-mirror, North —back. У всех четырёх одинаковые12×150ms и нормализованные
фазы i/12. Входящие параметры времени не заменяются придуманными анимационными FPS.

## World speed, рекомендации и Viewer

Viewer показывает все4направления одновременно и отдельно выбранное направление,
а также Original East / Aseprite Walk / Aseprite Run / New RD East. Есть pause/play,
scrub с выбором любого сравниваемого клипа, next/previous,0.5/1/2, native duration,
FPS, общая нормализованная фаза, Onion Skin, диагностические центроиды стоп и сетка32u.

Использованы реальный painter `groveArtPack.ts` в фазе `burning` и действующий Mage
из `public/assets/hd/mage.png`. Background создан из неизменённого production painter,
не выдан за новый сгенерированный фон. Его native pixels имеют worldScale0.5;
Mage64×80 —sourceScale0.375 с pivot32,60; Ash Warden logicalScale0.6548310811.
Game zoom1/2/3 — общий масштаб камеры, не изменение тела по bbox.

«Walking at World Speed» действительно перемещает землю относительно следующей
камеры на72/120/180/255units/s: East вправо, West влево, South вниз, North вверх.
Режим сохраняет native cycle1.8s; он **не подстраивает скрыто cadence для устранения
скольжения**.0.5/1/2масштабирует World и анимационное время вместе. Поэтому отсутствие
foot sliding не заявляется. На180/255с native Walking цикл слишком длинен для
убедительной синхронизации; этот Walking Pack не заменяет высокоскоростной Run.

В метаданных для East/West/South указан предварительный диапазон просмотра72–120,
с явной пометкой «не откалибровано по контакту». Это не готовая runtime-рекомендация
по cadence и не гарантия отсутствия скольжения. Для North диапазон не рекомендован
до исправления/принятия движения. Текущие скорости босса и Phase1/2/3 не менялись.

Изолированный сервер127.0.0.1:5198служит только новой папке. Общий Vite Viewer
не редактировался; HMR reload открытых игровых тестов не вызывается.
Скрипты Viewer и все изображения локальны; `viewer.html` можно открыть и как файл.

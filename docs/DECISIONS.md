цели на каждой стене (максимум две), slow использует max deadline/min factor,
без перемножения. Третья стена заменяет старейшую собственную; hostile warnings
не удаляются. Это ограниченное перекрытие сохраняет прежние правила эффектов.
Максимальный базовый урон одной стены48/72/96→72/126/192; это+50/75/100%.
Фактический урон зависит от времени цели внутриAB, защит и общих модификаторов.

Просьба «полоску хп чуть тоньше»: внутренняя высота6→5 world px, с прежней
рамкой8→7px; width34, anchor-33, depth11 и Absorb верхние2px сохранены.
Новые ресурсы, таймеры или Graphics не добавлены. Другие специализации,
базовые cooldown, AI/скорости/урон/частота атак/волны/прокачка не изменены.

Итоговая валидация: check304unit/45files, полный dev140/140 и production4/4,
включая realCanvas1280×720/390×844, zoom2/3 и stress150+3+3.
Оба seeded Mage39 positioning сценария120s завершены без тестовой неуязвимости.

Sprint/Berserk расширяют прежний BuffSystem конечными слотами временных модификаторов.

Порядок защиты: status/HP/i-frames/protection -> Arcane Shield charge (весь hit)

ниже снарядов12, friendly14 и tells20. Нет новых textures/timers/tweens.

HP/Absorb, основное изображение находится в Phaser. Длинная XP-row удалена,
рядом с уровнем показывается процент; XP/thresholds не меняются.

свободные boss slots, а не количество убийств конкретного автопилота: новый pool

Базовые файлы волн/HP/боссов/лимитов/XP проверены SHA256 в BASELINE.json.

## Encounter Director 2.0 — 2026-11-02

Новая работа в feature/encounter-director-2 от чистого main@57eb439. Разовое
разрешение публикации Combat Balance 2.0 завершено; текущий запрос запрещает
push/merge/deploy. Старые этапы06/16/21 прочитаны; новое прямое расписание и cap3
Guardian заменяют их прежние условия. Номерные done-маркеры не меняются.

Единственный EncounterDirector владеет минутными событиями:3B1,4G1,5B1,6G1,
7B2,8G2,9B3,10B3,11+ B3/G3. Он занимает только свободные слоты; избыточные
участники пропускаются навсегда для данного события. Живые враги не удаляются
ради расписания. При скачке времени выполняется только последняя текущая
минута; очередь отсутствует. История ограничена32 событиями. Боссы, уже
находящиеся в бою, получают коэффициенты текущей запланированной волны из базы,
не накопительно. Все caps из Combat Balance сохранены, кроме Guardian1→3.

Boss movement: масштабируется обычная ходьба/орбита всех трёх типов. Charger
сохраняет charge400px/s/.65s и точный260px телеграф; умножение этой скорости
без изменения траектории сделало бы предупреждение неверным. Частота реально
делит recovery и approach cooldown; начальное ожидание2s также делится на неё.
Предупреждения1.1s/1.25s и вторая volley Eclipse.6s не сокращаются. Поэтому
реальная частота полных циклов растёт медленнее номинального множителя cooldown.
HP и damage боссов не менялись. Коэффициенты ограничены1.6/2.0 после10min.

GuardianSystem хранит Map состояний по enemyId и группы наград, не таймер
случайных спавнов. Пробуждение от удара или дистанции<=64px. Safe spawn:>=240px
от героя, вне viewport с padding56px, между Guardian>=160px, до48 попыток.
До3 состояний/групп/визуальных corpse slots, отдельная HP/анимация/owner-danger.
Первое awakening смещено на0/.65/1.3s, чтобы три луча не включались в один кадр.
Остальные параметры лазера и метеоров сохранены. Leash фиксируется при активации
с учётом диаметра текущей группы+длины луча; убийство соседа не уменьшает его.
Это позволяет обойти несколько неподвижных целей. Timeout добивания из Combat
Balance сохранён. Уход одного отменяет только награду его группы, не удаляет
остальных. Смерть/restart/scene teardown очищают все состояния и owner-effects.

Одна успешно завершённая фактически появившаяся группа даёт один артефакт
текущего забега, автоматически при последнем убийстве. Это исключает потерю
гарантированной награды из-за заполнения пула физических предметов и не создаёт
очереди наград. Каждый участник отдельно сохраняет40XP/500очков. Частично
заполненная волна считается по реально назначенным участникам; при нуле новых
Guardian новая группа не создаётся. Повторный callback не выдаёт награду.
При достижении всех15 допустимых stacks новые Guardian всё равно появляются,
но дают только XP/очки: прежний cap3/type сохранён, исключение явно показано в UI.
Это не вечные артефакты между забегами; прежний reset при смерти/new run сохранён.

При >=3 крупных активных угрозах скрываются декоративные elite overlays и
damage numbers; реальные предупреждения Caster/Rusher/боссов/Guardian сохраняются.
После встречи с>=4 крупными участниками8s частота обычного спавна составляет75%
исходной, затем автоматически возвращается. Живые обычные мобы/HP/cap150 не
меняются. Уведомления используют время симуляции и не ставят игру на паузу.
UI показывает тип встречи, отдельные группы Guardian и прогресс общей награды.
Мобильные артефакты собраны в один ряд значков с процентами и числом копий;
полные названия/эффекты сохранены в aria-label/title. Высота вспомогательной
колонки ограничена свободной областью ниже героя, длинное содержимое прокручивается.
Это исправляет обнаруженное HD UI regression перекрытие центра при пяти артефактах,
двух баффах, уведомлении и прогрессе Guardian; проверка перекрытий сохранена.

Исторические JSON Combat Balance 2.0 не перезаписываются текущими regression
benchmarks: их промежуточные результаты направлены в .tmp. Новые измерения
